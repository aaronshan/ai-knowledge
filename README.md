# ai-knowledge

本仓库用于汇总 AI 及大模型（LLM）相关的知识资料，包括 arXiv 论文、技术文档等。资料按来源分类存放，部分论文同时提供英文原文与中文译文。

## 目录结构

- `arxiv/` — arXiv 论文资料
  - `arxiv/origin/` — 英文原文
  - `arxiv/chinese/` — 中文译文
